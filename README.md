# SOLARIS v1.0.0

SOLARIS 是一个以「从太阳系走向宇宙」为主线的交互式三维宇宙探索网站。当前发布版本为 **SOLARIS v1.0.0**，以单一 HTML 文件交付，可直接静态部署到 GitHub Pages。

## 核心体验

### 太阳系与深空探索

- 太阳、八颗行星、月球与主要卫星的三维场景；
- 地球近景、地月空间、太阳系、银河系和宇宙网的连续尺度旅程；
- 天体导航、目标聚焦、动态跟踪和自由观察；
- 月球着陆、月面步行、私人月球飞船、地月空间航行与月面勘探任务；
- 深空任务中心、引力辅助、轨道转移、发射窗口、行星捕获、推进预算和轨道精度实验室；
- 四条引导路线、地月系统、食现象实验室、恒星演化博物馆和引力沙盒。

### 宇宙剧场

右上角「宇宙剧场」提供三类十个现有场景的统一入口：

- **宏观宇宙**：宇宙演化史、宇宙网穿越、银河系全景与穿越；
- **深空奇观**：双星系碰撞、星系团碰撞、黑洞、星云；
- **恒星与宇宙演化**：超新星、恒星诞生、行星形成。

每个场景支持原生全屏欣赏、暂停、继续、重播、自由观察和退出场景。

### 全屏欣赏

- 主应用右上角常驻全局全屏按钮；
- 全屏覆盖主画布、HUD 和必要操作界面；
- 支持浏览器原生全屏、Esc 退出和全屏拒绝回退；
- 宇宙剧场保留自己的全屏按钮，并与全局全屏状态同步。

## 基本操作

### 通用

- 鼠标拖动：旋转视角；
- 滚轮：缩放；
- 右键拖动：平移；
- 左侧导航：选择天体、实验室或路线；
- 右上角：宇宙剧场、宇宙演化史、全局全屏。

### 月球与飞船

- `WASD`：月面行走或飞船水平控制；
- `F`：登船 / 下船 / 着陆 / 返回月面；
- `Space`：起飞 / 上升；
- `C`：下降；
- `B`：制动；
- `T`：高度足够时进入地月空间；
- `V`：切换舱内 / 舱外视角；
- `L`：释放鼠标指针。

### 宇宙剧场

- 播放 / 暂停；
- 0.5× / 1× / 2×（按场景支持）；
- 重播；
- 自由观察 / 回到镜头；
- 退出场景；
- Esc 退出全屏；
- 手动旋转、缩放后不会被自动镜头强行拉回。

## 浏览器与网络要求

- 现代 **Chrome / Edge** 桌面浏览器；
- 支持 **WebGL2**；
- 建议启用 GPU 硬件加速；
- 双击 `index.html` 或通过静态 HTTP 服务打开；
- **不需要 Node.js、npm、服务器端程序或网络**；
- JavaScript、CSS 和 16 张纹理全部内联在 `index.html` 中；
- 没有外部 CDN、远程字体、远程纹理或 API 请求。

GitHub Pages 通过 HTTPS 提供服务，原生全屏、指针锁定和 WebGL2 均可在支持这些能力的桌面浏览器中使用。

## 已知限制

- 这是一个科学启发的程序化可视化项目，不是完整的宇宙学 N 体、流体或辐射转移模拟。
- 星系、宇宙网、黑洞、碰撞和演化场景以电影化/教学化近似为主；具体精度见项目内说明。
- 移动端目前以基本布局、菜单和 HUD 为主，**没有触摸式飞船或月面控制**；完整飞行依赖桌面键盘。
- 最终浏览器验收以 Chrome 桌面为主；未对 Edge、Firefox、Safari 做同等完整的最终回归。
- 原生全屏依赖浏览器 Fullscreen API、用户手势和浏览器策略；不支持时会进入普通沉浸视图。
- 深空实验室内部数值流程、月面勘探的长距离驾驶和四条路线的完整电影式停留，部分由自动化测试覆盖，未全部手动重演。
- 性能取决于 GPU、窗口尺寸、浏览器和后台负载。
